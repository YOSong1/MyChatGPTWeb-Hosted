# MyChatGPTWeb 사용 안내 (웹 접속판)

설치할 것은 없습니다. 선생님이 알려준 주소로 접속해 발급받은 OpenAI API Key를 넣으면 됩니다.

---

## 1. 접속

1. 브라우저(Chrome, Edge, Safari 등)에서 선생님이 알려준 주소를 엽니다.
2. "This app has gone to sleep" 화면이 나오면 **Yes, get this app back up!** 버튼을 누르고 1분쯤 기다립니다. 한동안 아무도 쓰지 않으면 잠들었다가 첫 접속 때 깨어납니다.
3. 접속을 허용된 사람만 볼 수 있게 설정된 경우, 선생님께 알려드린 이메일로 로그인하라는 화면이 먼저 나옵니다.

## 2. API Key 입력

"API Key를 입력하세요" 화면에 발급받은 키(`sk-`로 시작)를 붙여넣고 **연결 확인 후 시작**을 누릅니다.

꼭 알아 둘 점
- 키는 **서버에 저장되지 않습니다.** 이 서버는 키를 OpenAI에 전달만 합니다.
- **탭을 닫거나 새로고침하면 키와 대화가 모두 사라집니다.** 다시 접속하면 키를 다시 넣어야 합니다.
- "키가 올바르지 않습니다"가 나오면 앞뒤 공백 없이 키 전체를 복사했는지 확인하세요.

## 3. 사용법

- 아래 입력창에 질문을 쓰고 Enter를 누르면 답이 나옵니다. 줄바꿈은 Shift+Enter.
- 왼쪽 **➕ 새 대화**로 주제를 나눠 대화할 수 있습니다. 🗑 로 삭제합니다.
- 왼쪽 **모델**에서 답변 모델을 고릅니다. 위쪽이 최신, `mini`/`nano`가 붙은 것이 빠르고 저렴합니다.
- 답변 아래 **🔁 다시 생성**을 누르면 마지막 답을 새로 받습니다.
- 답변에 코드가 있으면 **💾 snippet-1.py** 같은 저장 버튼이 생깁니다.

### 입력창 위의 두 스위치
- **🌐 웹 검색**: 오늘 날씨, 최신 뉴스처럼 최근 정보가 필요한 질문에 인터넷을 검색해 답하고 "출처"에 링크가 붙습니다.
- **📎 파일 생성**: 켜고 "~를 pptx로 만들어줘", "이 표를 엑셀로 만들어줘"처럼 요청하면 실제 파일을 만들어 **📎 파일이름** 다운로드 버튼이 생깁니다. **파일은 바로 내려받으세요.** 탭을 닫으면 다시 받을 수 없습니다.
- 켜져 있을 때만 약간의 추가 요금이 붙습니다. 평소에는 꺼 두세요.

## 4. 대화 남겨 두기

대화는 탭 안에서만 유지됩니다. 남겨 두고 싶으면 왼쪽 **⚙️ 설정 → 📤 대화 내보내기 (JSON)** 로 파일을 받아 두고, 다음에 **📥 대화 가져오기**로 불러오면 이어서 볼 수 있습니다.

## 5. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 앱이 잠들었다는 화면 | "Yes, get this app back up!" 누르고 1분 대기 |
| "요청 한도를 초과했거나 크레딧이 없습니다" | 키의 사용 한도가 찼습니다. 선생님께 문의 |
| "모델을 사용할 수 없습니다" | 왼쪽에서 다른 모델(예: gpt-4o-mini) 선택 |
| 화면이 멈추거나 이상함 | 새로고침. 키는 다시 넣어야 합니다 |
| 다른 키로 바꾸고 싶음 | ⚙️ 설정 → **키 변경 / 삭제** |
