# MyChatGPTWeb 설치 및 사용 안내

발급받은 OpenAI API Key로 ChatGPT처럼 대화할 수 있는 프로그램입니다.
인터넷만 연결되어 있으면 되고, 별도 설치 프로그램은 필요 없습니다.

---

## 1. 내 컴퓨터에 맞는 파일 받기

공유받은 Google Drive 폴더에서 아래 중 하나를 받으세요.

| 내 컴퓨터 | 받을 파일 |
|---|---|
| Windows | `MyChatGPTWeb-<버전>-windows-x64-onedir.zip` |
| Mac (Apple Silicon: M1, M2, M3, M4) | `MyChatGPTWeb-<버전>-macos-arm64.zip` |
| Mac (Intel) | `MyChatGPTWeb-<버전>-macos-x64.zip` |

Mac 칩 종류 확인: 화면 왼쪽 위 **Apple 메뉴 > 이 Mac에 관하여**에서 "칩" 항목을 보세요. "Apple M..."이면 Apple Silicon입니다.

다운로드 중 이런 메시지가 나올 수 있습니다.
- Google Drive: "바이러스 검사를 할 수 없습니다" → **그래도 다운로드**
- Chrome: "일반적으로 다운로드되지 않는 파일입니다" → 화살표 클릭 후 **계속**

---

## 2. 압축 풀고 실행하기

### Windows
1. zip 파일을 우클릭 → **압축 풀기**. 바탕화면이나 문서 폴더처럼 한글이 없는 경로가 안전합니다.
2. 풀린 폴더 안의 `MyChatGPTWeb.exe`를 더블클릭합니다.
3. "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보** → **실행**을 누릅니다.
4. 검은 창이 열리고 몇 초 뒤 브라우저가 자동으로 열립니다.

### Mac
1. zip 파일을 더블클릭해 압축을 풉니다. `MyChatGPTWeb.app`이 생깁니다.
2. `MyChatGPTWeb.app`을 **응용 프로그램** 폴더로 옮깁니다(선택).
3. 처음 실행할 때 "확인되지 않은 개발자" 또는 "열 수 없습니다" 경고가 뜹니다. macOS 버전에 따라 방법이 다릅니다.
   - **macOS 14 이하**: 앱을 **우클릭(또는 control+클릭) → 열기** → 다시 **열기**
   - **macOS 15 이상**: 한 번 더블클릭해 경고를 닫은 뒤, **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽 "MyChatGPTWeb이(가) 차단되었습니다" 옆의 **그래도 열기**를 누릅니다.
4. "손상되었기 때문에 열 수 없습니다"라고 나오면 **터미널**을 열고 아래를 붙여넣은 뒤 Enter를 누르고 다시 실행합니다.
   ```
   xattr -cr ~/Downloads/MyChatGPTWeb.app
   ```
   (앱을 다른 곳에 두었다면 경로를 그에 맞게 바꾸세요.)
5. 터미널 창이 열리고 몇 초 뒤 브라우저가 자동으로 열립니다.

---

## 3. 처음 한 번: API Key 입력

브라우저 화면에 "API Key를 입력하세요"가 나오면 발급받은 키(`sk-`로 시작)를 붙여넣고 **연결 확인 후 시작**을 누릅니다.

- 키는 **내 컴퓨터에만** 저장됩니다. 선생님이나 다른 사람에게 전송되지 않습니다.
- 학교 공용 PC처럼 다른 사람도 쓰는 컴퓨터라면 **"이 컴퓨터에 기억하기"를 끄세요.** 프로그램을 종료하면 키가 지워집니다.
- "키가 올바르지 않습니다"가 나오면 앞뒤 공백 없이 키 전체를 복사했는지 확인하세요.

### 키 입력 화면을 건너뛰고 싶다면 (선택)
컴퓨터의 환경변수 **`OPENAI_API_KEY`** 에 키를 등록해 두면 프로그램이 알아서 읽어 바로 채팅 화면으로 시작합니다. 키 입력 화면 아래 "환경변수로 등록하는 방법"에 순서가 적혀 있습니다.
- Windows: PowerShell에서 `setx OPENAI_API_KEY "sk-여기에키"` 실행 후 프로그램 재시작
- Mac: Finder에서 더블클릭으로 실행하면 환경변수를 읽지 못합니다. 터미널에서 실행할 때만 적용되므로, Mac에서는 키 입력 화면에서 "이 컴퓨터에 기억하기"를 켜는 편이 간단합니다.

---

## 4. 사용법

- 아래 입력창에 질문을 쓰고 Enter를 누르면 답이 나옵니다. 줄바꿈은 Shift+Enter.
- 왼쪽 **➕ 새 대화**로 주제를 나눠 대화할 수 있습니다. 🗑 로 삭제합니다.
- 왼쪽 **모델**에서 답변 모델을 고릅니다. 위쪽이 최신, `mini`/`nano`가 붙은 것이 빠르고 저렴합니다.
- 왼쪽 **⚙️ 설정**에서 도우미의 역할(시스템 프롬프트)을 바꾸거나 대화를 파일로 내보낼 수 있습니다.
- 답변 아래 **🔁 다시 생성**을 누르면 마지막 답을 새로 받습니다.

---

## 5. 종료와 재실행

- **종료**: 프로그램을 실행할 때 열린 검은 창(Mac은 터미널 창)을 닫으면 끝납니다. 브라우저 탭만 닫으면 프로그램은 계속 떠 있습니다.
- **재실행**: 다시 더블클릭하면 됩니다. 이전 대화는 그대로 남아 있습니다.
- 브라우저가 자동으로 열리지 않으면 주소창에 `http://localhost:8765` 를 입력하세요.

## 6. 문제가 생겼을 때

| 증상 | 해결 |
|---|---|
| 검은 창이 잠깐 떴다 사라짐 | 백신 프로그램이 막았을 수 있습니다. 선생님께 문의하세요. |
| "요청 한도를 초과했거나 크레딧이 없습니다" | 키의 사용 한도가 찼습니다. 선생님께 문의하세요. |
| "모델을 사용할 수 없습니다" | 왼쪽에서 다른 모델(예: gpt-4o-mini)을 선택하세요. |
| "서버에 연결할 수 없습니다" | 인터넷 연결을 확인하세요. |
| 처음부터 다시 하고 싶음 | ⚙️ 설정 → **키 변경 / 삭제** |

대화 기록과 설정은 아래 폴더에 저장됩니다. 프로그램을 지워도 남으며, 완전히 지우려면 이 폴더를 삭제하세요.
- Windows: `%APPDATA%\MyChatGPTWeb`
- Mac: `~/Library/Application Support/MyChatGPTWeb`
